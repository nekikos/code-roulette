## 📖 О плагине

**Code Roulette** — тренажёр, который проверяет, правда ли ты понимаешь свой код.

1. 🎡 Открываешь C/C++ файл и крутишь неоновую рулетку, на секторах которой написаны имена твоих функций.
2. 💥 Рулетка останавливается на случайной функции, и плагин **стирает её тело**. Заголовок остаётся.
3. ⏱ Запускается таймер на 3, 5 или 10 минут.
4. ⌨️ Пишешь функцию заново и жмёшь **«ГОТОВО»**. Плагин собирает проект и запускает тесты.
5. 🎉 Тесты прошли — **победа** и конфетти. Не успел или тесты упали — **поражение**.

А ещё рулеткой можно **принимать лабы**: практик запускает **режим экзамена** с PIN-кодом,
студент проходит несколько раундов, а в конце получается отчёт с журналом всех подозрительных моментов.

```cpp
int binarySearch(int* a, int n, int x) {
    // 🎰 TODO: напиши эту функцию заново!
}
```

## ✨ Возможности

| Возможность | Описание |
|---|---|
| 🎡 Неоновая рулетка | колесо с функциями файла, плавное вращение, звук щелчков и мигающие лампочки |
| 🎯 Честный случайный выбор | недавно выпавшие функции (последние 3) не повторяются |
| 🟢🟡🔴 Уровни сложности | лёгкий — короткие функции, средний — любые, **адский — длинные и сразу две** («⚡ двойной удар») |
| ✂️ Стирание тела функции | заголовок остаётся, вместо тела — `// TODO`, курсор сразу в нужном месте |
| ⏱ Таймер на выбор | кнопки **3 / 5 / 10 минут**, кольцо обратного отсчёта, в последнюю минуту краснеет и пульсирует |
| 📟 Таймер в строке состояния | `🎰 04:59 · binarySearch` виден, даже если панель закрыта |
| ✅ Автоматическая проверка | своя команда сборки и тестов, например `cmake --build build && ctest --test-dir build` |
| 🚫 Защита от читерства | Ctrl+Z, вставка оригинала или откат файла ловятся: тело стирается снова, **−30 секунд** |
| 🔌 Закрыл VS Code — время идёт | раунд хранится на диске и продолжается после перезапуска, таймер считает реальное время |
| 📓 Журнал раунда | уходы из VS Code, большие вставки, Ctrl+Z, закрытие VS Code, подсказки — с точным временем |
| 💡 Подсказки | следующая строка оригинала за **−60 секунд** |
| 🎓 Режим экзамена | практик задаёт студента, число раундов, время, сложность, подсказки и команду проверки; всё под PIN-кодом |
| 🔒 Замок практика | после каждого раунда экзамена время замирает, результат скрыт до PIN практика — переиграть втихую нельзя |
| 🖥 Полный экран | на экзамене VS Code разворачивается в Zen Mode — меньше соблазна отвлекаться |
| 📄 Отчёт экзамена | `roulette-report-*.md` в папке проекта: итог, таблица раундов, журнал событий |
| 🏆 Достижения | 9 неоновых значков: «Первая кровь», «Молния», «Из ада», «Пойман» и другие |
| ↩ Возврат оригинала | кнопки «Сдаться», «Вернуть оригинал» и «Показать оригинал» |
| 💾 Резервная копия | оригинал функции сохраняется в файл до стирания, код не потеряется |
| 🏆 Статистика | победы, поражения, серия побед 🔥 и рекорд по времени; сохраняются между запусками |
| 🎉 Эффекты | конфетти и фанфары при победе, глитч-эффект при поражении, тряска экрана при читерстве |

## 🚀 Установка и запуск

**Нужно:** [Node.js](https://nodejs.org/) 18+ и [VS Code](https://code.visualstudio.com/) 1.80+.

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Собрать проект:

   ```bash
   npm run compile
   ```

3. Открыть папку проекта в VS Code и нажать **F5**. Откроется новое окно VS Code с подключённым плагином.
4. Открыть в этом окне [`examples/algorithms.cpp`](examples/algorithms.cpp) и нажать **🎰 Рулетка** в строке состояния внизу.

### Запуск тестов

```bash
npm test
```

## 🎮 Как играть

| Шаг | Что делать |
|---|---|

## 🎓 Режим экзамена (для практика)

1. Открыть рулетку и нажать **🎓** в правом верхнем углу панели
   (или `Ctrl+Shift+P` → **Code Roulette: начать экзамен (для практика)**).
2. В форме выбрать ФИО и группу студента, число раундов (1–5), минуты на раунд, сложность,
   включить или выключить подсказки, задать команду проверки и **PIN-код** — и нажать **🎓 НАЧАТЬ ЭКЗАМЕН**.
3. Передать компьютер студенту. На панели появится жёлтая полоса **🎓 ЭКЗАМЕН · РАУНД 1/3**,
   выбор времени и сложности скрыт — их задал практик. Во время раунда VS Code на весь экран.
4. Студент жмёт «ГОТОВО» (или время вышло, или сдался) — появляется **🔒 РАУНД ЗАВЕРШЁН**:
   время остановлено, результат скрыт. Практик подходит, вводит PIN — и видит результат и журнал.
5. После последнего раунда (и PIN) отчёт сохраняется в папку проекта и сразу открывается.
6. Остановить экзамен досрочно: кнопка **⏹ СТОП** в жёлтой полосе и PIN
   (или команда **Code Roulette: остановить экзамен**).

Что видит практик в отчёте:

| Пункт | Пример |
|---|---|
| Итог | **2 из 3** раундов выиграно |
| По каждому раунду | функции, результат, время `01:35 / 05:00` |
| Подозрительное | 🪟 уходил из VS Code 2 раза (01:05), 📋 вставка 140 символов, 🚫 Ctrl+Z, 🔌 закрывал VS Code |
| Журнал | `[02:15] 📋 Вставка 120 символов` — каждое событие с секундой раунда |

Что защищено:
- **PIN хранится только хешем** (SHA-256 с солью) — подсмотреть его в настройках нельзя;
- **команда проверки фиксируется** при старте — студент не подменит её на `exit 0`;
- **закрытие VS Code не спасает**: раунд продолжается, время идёт, в журнале остаётся запись;
- **замок нельзя обойти перезапуском или другой папкой**: он хранится во всём VS Code, а не в проекте,
  и пока он висит, крутить рулетку и начинать новый экзамен нельзя; неверные PIN попадают в отчёт.

| Попытка обойти | Что будет |
|---|---|
| Закрыть VS Code на замке | после запуска замок снова на экране |
| Открыть другую папку | замок висит в любой папке |
| Удалить отчёт и переиграть | отчёт появляется только после PIN; новый экзамен без PIN не начать, пока идёт текущий |
| Подбирать PIN | каждая неверная попытка записывается в отчёт |
| Удалить плагин, другой профиль или компьютер | не закрывается на стороне студента — но практик рядом и видит, что замка нет |

> ⚠️ Честно: плагин работает на компьютере студента и его код открыт, поэтому сдача «из дома»
> даёт **улики, а не доказательство**. Самый надёжный вариант — экзамен вживую.

## ⚙️ Настройки

| Настройка | По умолчанию | Описание |
|---|---|---|
| `codeRoulette.checkCommand` | *(пусто)* | команда проверки, запускается в папке проекта; код выхода `0` = победа. Если пусто, победа засчитывается, если успел до конца таймера |
| `codeRoulette.skipMain` | `true` | не выбирать функцию `main` |
| `codeRoulette.minLines` | `2` | минимальная длина тела функции (строк), чтобы она попала на колесо |

Примеры команды проверки:

```bash
cmake --build build && ctest --test-dir build
```

```bash
g++ -std=c++17 main.cpp -o app && ./app < tests/input.txt
```

## ⚠️ Ограничения

- Играем с одним файлом — тем, что открыт в редакторе.
- Перегруженные операторы (`operator<<`) и лямбды не попадают на колесо.
- Защита от читерства ловит возврат большого куска оригинала разом. Если перепечатать функцию по памяти, это не читерство, а победа 😉
- Если функция совсем короткая (меньше 30 символов без пробелов), Ctrl+Z на ней не ловится.
- Журнал фиксирует подозрительное, но не может доказать списывание: удаление плагина или его данных он не переживёт.
