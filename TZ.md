# ТЗ: плагин Code Roulette для VS Code

## Назначение
Тренажёр для программиста: плагин случайно выбирает функцию в C/C++ файле, стирает её тело
и даёт ограниченное время, чтобы написать её заново.

## Функции
1. Команда «Code Roulette: открыть рулетку» и кнопка 🎰 в строке состояния открывают панель с рулеткой.
2. Плагин находит все функции в открытом C/C++ файле и показывает их на секторах колеса.
   - `main` по умолчанию не участвует (настройка `codeRoulette.skipMain`).
   - Функции с телом короче `codeRoulette.minLines` строк не участвуют.
3. Перед вращением выбирается время: 3, 5 или 10 минут (кнопки на панели).
4. Кнопка «КРУТИТЬ»: колесо вращается с анимацией и останавливается на случайной функции.
   Функция, выпавшая недавно (последние 3 раза), повторно не выпадает, если есть другие.
5. После остановки тело выбранной функции заменяется на комментарий `// TODO`,
   заголовок функции остаётся. Курсор переводится в эту функцию.
6. Запускается таймер: он виден на панели и в строке состояния; последнюю минуту подсвечивается.
7. Кнопка «ГОТОВО»: файл сохраняется и запускается команда проверки из настройки
   `codeRoulette.checkCommand` (например, `cmake --build build && ctest --test-dir build`).
   Код выхода 0 — победа, иначе — поражение, вывод команды показывается в панели «Output».
   Если команда не задана — победа засчитывается, если успел до конца таймера.
8. Если время вышло — поражение.
9. Кнопка «СДАТЬСЯ» и действие после поражения «Вернуть оригинал» возвращают исходное тело функции.
   Кнопка «Показать оригинал» открывает исходный код функции в отдельной вкладке.
10. Оригинал функции до удаления сохраняется в файл резервной копии, чтобы код нельзя было потерять.
10а. Защита от читерства: если во время раунда в функцию одной правкой возвращается большой
   кусок оригинала (Ctrl+Z, вставка из буфера, откат файла), тело стирается снова,
   из оставшегося времени вычитается 30 секунд, на панели показывается предупреждение.
   Число попыток выводится в результате раунда.
10б. Раунд хранится на диске: если закрыть VS Code, после запуска раунд продолжается,
   а время, пока VS Code был закрыт, засчитывается. Если время вышло — поражение.
10в. Журнал раунда: уходы из VS Code (от 3 секунд), большие вставки (от 30 символов),
   попытки Ctrl+Z, закрытия VS Code, подсказки — с секундой раунда. Итоги видны после раунда.
10г. Подсказка: следующая строка оригинала, штраф −60 секунд.
10д. Сложность: лёгкий (короткие функции), средний (любые), адский (длинные, две функции за раунд).
10е. Режим экзамена для практика: ФИО студента, 1–5 раундов, время, сложность, подсказки,
   команда проверки и PIN-код (хранится хешем). Студент не может менять настройки;
   остановить экзамен можно только с PIN. В конце — отчёт `roulette-report-*.md` в папке проекта.
10ж. Достижения (9 штук) с всплывающей анимацией и окном просмотра.
11. Статистика: победы, поражения, серия побед подряд, лучшее время. Сохраняется между запусками VS Code.
12. Оформление панели — неоновый стиль: светящееся колесо, анимированные кнопки, конфетти при победе.

## Состояния игры
`idle` (ожидание) → `spinning` (вращение) → `solving` (решение, идёт таймер) →
`checking` (проверка) → `finished` (результат) → `idle`.
Переходы описаны таблицей; недопустимый переход игнорируется.

## Структуры данных и алгоритмы
- Конечный автомат для удаления комментариев и строк перед разбором кода.
- Стек фигурных скобок для поиска границ функций.
- Конечный автомат состояний игры (таблица допустимых переходов `Map<состояние, состояния[]>`).
- Очередь последних выпавших функций (чтобы не повторялись).
- Объект статистики, сохраняемый в хранилище VS Code.
- Сравнение текстов без учёта пробелов для распознавания вставки оригинала.
- Журнал событий (список) и подсчёт итогов по нему.
- Отбор функций по медиане длины тела для уровней сложности.
- Хеширование PIN-кода (SHA-256 с солью).
- Список достижений и множество уже открытых.

## Ограничения
- Поддерживается один файл за игру (активный редактор).
- Перегруженные операторы и лямбды не считаются отдельными функциями.
